# The Lucky Ducks token

There is one Lucky Ducks token, and the token page at theluckyducks.com/token is where to check it before you trust it. Everything on the page is read from the chain or published by the platform, so you can compare it with what your wallet and an explorer show.

## The address

The token's address, its mint, is printed in full with a button that copies it. **Check every character, not just the first and last few**: a fake token can be made to share both.

{% hint style="danger" %}
Nobody from the project will message you first, ask for your seed phrase, or offer tokens anywhere but on these pages. A token using the name with any other address is not this one.
{% endhint %}

## What can still change

The page shows the token's live supply and three facts about who can still change it:

- whether anyone can still **mint** more tokens;
- whether anyone can **freeze** a holder's account;
- whether anyone can still change the token's **name, symbol or image**.

Each is read from the token itself, so it is what the chain says today.

<figure><img src="../../.gitbook/assets/token/app-token-facts-banner.png" alt="The token's facts: the supply and whether minting, freezing and metadata changes are still possible"><figcaption><p>Read from the chain each time the page loads.</p></figcaption></figure>

## Where the supply sits

Every allocation of the supply is listed: its share, the wallet that holds it, the lock it is released through, and how much of it has been released so far. Every release starts at the liquidity launch, and none runs past 12 months. A lock is held by its provider, so the page links to it there as well.

<figure><img src="../../.gitbook/assets/token/app-token-allocations-banner.png" alt="The allocations table: each allocation's share, wallet, lock and how much has been released"><figcaption><p>Each lock links to its provider, where you can check it yourself.</p></figcaption></figure>

## The official pool

The page names the one official pool, the pool the token trades in against SOL, with its locked position and the date trading opens. **Any pool before that date is not the project's.**

## Giveaway races

Tokens are also given away in free races the platform sponsors, with no entry fee. Every one is listed on the page with who won what, so every token given away is accounted for.
